# The Smart Medical System

The Smart Medical System is a Kotlin-based health simulation app featuring secure user authentication and a professional admin dashboard that tracks system data in real time.
****
**Feature**

some features are:

-- **A patients dashboard** Patients can add and update their ongoing medicine schedules.

--**An Admin Dashboard** Allows administrators to oversee overall system performance.

--**A Doctor Dashboard** Doctors can view and manage appointment bookings from system users.
